# FOODORA Restaurant Website

React + Vite + Tailwind CSS + Three.js + Lucide React.

## Run locally
```
npm install
npm run dev
```
Open the address shown in the terminal (usually http://localhost:5173).

## Deploy to GitHub Pages
1. Open `vite.config.js` and replace `YOUR-GITHUB-REPOSITORY-NAME` with your exact repository name.
2. Push to the `main` branch of that repository.
3. On GitHub: Settings -> Pages -> Source: **GitHub Actions**.
4. Your site appears at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`.
